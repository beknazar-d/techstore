## 2026-11-17 — Админка: Telegram-бот (настройки и чаты)

- Сделано: раздел «Настройки» (`/admin/settings`): подключение бота по токену от @BotFather, включение и выключение, ID группы менеджеров, выбор уведомлений, тестовое сообщение, ИИ-ответы (приветствие, инструкция, торг до `minPrice`, заявки от бота, передача менеджеру). Раздел «Чаты» (`/admin/chats`, `/admin/chats/:id`): переписка бота с клиентами, фильтр по режиму, ответ менеджера, кнопки «Ответить самому», «Вернуть боту», «Закрыть». В меню счётчик чатов, где ждут менеджера.
- Ключевые файлы: `src/api/bot.ts`, типы `BotSettings`/`BotChat`/`BotMessage` в `src/types/index.ts`, демо-данные `createBotSeed` в `src/data/seed.ts`, страницы `src/admin/pages/SettingsPage.tsx`, `ChatsPage.tsx`, `ChatPage.tsx`.
- Решения: токен бота во фронтенде не хранится, даже локально: запоминаются только последние 4 символа. В Supabase-версии токен сохраняет Edge Function `telegram-setup` (getMe + setWebhook), сообщения принимает `telegram-webhook`, ответ менеджера отправляет `telegram-send`. Ответ менеджера переводит чат в режим `manager`, и бот в этом чате замолкает. Старые локальные данные дополняются чатами без пересоздания базы (`upgradeDb` в `db.ts`). На телефоне «Настройки» открываются шестерёнкой в верхней полосе, в нижней панели 5 пунктов.
- Сейчас бот не настоящий: 3 демо-чата, ответы пишутся в консоль.
- Дальше: проверить разделы руками в браузере; настоящий бот — вместе с Supabase (Edge Functions + LLM).
